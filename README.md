# Rounak Thakur’s portfolio

Personal portfolio hosted at https://nurarara.github.io/ with GitHub Pages.

## Edit and preview

This is a static site. Edit `index.html`, `assets/portfolio.css`, and `assets/portfolio.js` directly. No package installation or build step is required.

Run `python -m http.server 4173 --bind 127.0.0.1` from the repository, then visit http://127.0.0.1:4173/. The existing GitHub Actions workflow publishes pushes to `main`.

Project filtering and the compact phone menu progressively enhance the HTML. All projects and navigation links remain available without JavaScript. Motion respects the visitor’s reduced-motion setting.

## Content and assets

- Existing experience, education, skills, contact details, and résumé are retained from the original portfolio.
- Claude Certified Architect – Foundations is listed at the owner’s request. The link explains Anthropic’s certification, rather than verifying an individual credential. The image-heavy ring hero was replaced because eighteen distinct project photographs were unavailable; the portrait and venue contact layouts were replaced because this portfolio has neither a portrait nor a visitor-facing venue.

No analytics, cookies, API keys, server, or paid services are required.
